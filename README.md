# 明远湖光 · DSH 校园服务

面向四川大学的 DeepSeek Harness 插件。校园协议源自 [明远湖光](https://github.com/AzureKyrielight/MingYuanHu)，不启动第二套 Electron 应用或 Agent 内核。

## 范围

- 在 DSH 设置中的校园账号面板登录统一身份认证；支持本地验证码识别与手动输入。
- 向 Agent 提供登录状态、学期、成绩、课表和电费查询工具。
- 电费只读查询本人已有房间绑定，不自动绑定房间，不缴费。
- 不提供选课、报名、报修提交、打印上传或其他校园写操作。
- 复用 DSH 的 `web_search`、`web_fetch` 与会话能力，不替换宿主工具。

## 安装

需要 DeepSeek Harness 0.2.2-rc.2。首次版本只针对该版本验证，不承诺兼容后续运行时。

在 DSH 的 **插件 → 添加插件** 中选择本仓库目录，或选择已发布的 npm 包名 `dsh-mingyuanhu`。本地目录安装前需要先构建。是否需要重启，以 DSH 安装结果为准。

```sh
npm ci --ignore-scripts --legacy-peer-deps
npm run check
npm pack
```

## 使用

1. 在 DSH 设置中打开校园账号面板。
2. 输入学号与统一认证密码。验证码自动识别失败时，切换手动输入。
3. 登录后向 Agent 请求查询成绩，或先列出学期，再查询指定学期课表。
4. 电费查询使用现有本人房间绑定。未绑定时请在学校官方服务中完成绑定。
5. 不再使用时退出校园账号，清除插件保存的本地会话。

## 隐私与限制

密码不注册为模型工具参数，不写入聊天记录，不持久化。选择记住登录状态时，token 与 cookie 通过 DSH 的 credentials 记录保存，不写入工作区。credentials 后端决定实际存储保护方式；它不构成对同 OS 用户工具或其他宿主插件的秘密隔离。不要在不信任的 DSH 配置中登录。

查询结果会进入 Agent 会话，并可能发送给所选模型服务。成绩、课表、住宿信息属于个人数据；请先了解模型服务和 DSH 的会话日志策略。退出只清除校园认证状态，不删除历史聊天结果。

校园请求仅访问 `scu.edu.cn` 及其子域。学校教务系统使用 HTTP，无法由插件提供端到端 TLS 保护。部分服务需要校园网或 VPN；学校接口、验证码与登录策略可能变更。插件不承诺自动续期，不保存密码。

此插件不是学校或 DeepSeek 的官方产品。

## 架构

- `src/core`：不依赖 DSH、Pi 或 Electron 的校园认证、cookie 与业务协议。
- Host 适配：只读模型工具、用户专用认证入口、DSH credentials。
- Client 适配：复用宿主 React 与主题，密码不进入模型调用链。

登录、退出和查询复用同一业务实例。校园认证传输与公开网页抓取严格分离。

## 开发与验证

```sh
npm run typecheck
npm test
npm run build
```

自动化测试使用本地响应，不登录真实账号，不进行校园写操作。真实账号、网络可达性与界面视觉验证须在使用者本机进行。测试通过不等于学校服务当前可用。
